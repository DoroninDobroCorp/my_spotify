# My Spotify Export Data

Автоматический экспорт медиатеки Spotify в формат CSV.

## 📊 Экспортированные файлы:
- **`liked_tracks.csv`** — Список любимых треков (3,289 треков).
- **`saved_albums.csv`** — Список сохраненных альбомов (1,635 альбомов).
- **`playlists.csv`** — Плейлисты и их содержимое.

## 🚀 Запуск скрипта экспорта:
```bash
pip install spotipy
python export_spotify.py
```
